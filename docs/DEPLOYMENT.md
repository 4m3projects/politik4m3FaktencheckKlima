# Veröffentlichung über GitHub Pages

1. Pull Request prüfen und nach `main` zusammenführen.
2. Repository Settings → Pages → Build and deployment → Source: **GitHub Actions** wählen.
3. Unter Actions den Workflow **Klima-Faktencheck Webseite** starten oder den nächsten Push auf `main` abwarten.
4. Die Adresse ist voraussichtlich https://4m3projects.github.io/politik4m3FaktencheckKlima/ .
5. Erst nach erfolgreichem Test und vorhandenen geprüften Videos die Hauptseite verlinken (erledigt am 20.11.2026: Menü am Seitentitel auf allen drei Seiten).

Bei null Videos bleibt `daten/index.json` leer. Ein späterer Import muss den Index sowie die zugehörigen strukturierten Daten und Berichte erzeugen. Keine unverifizierten Video-Datensätze veröffentlichen.
